## TL;DR

- 迷ったら **Yubico Security Key C NFC を 2 本** で十分です。パスキー（FIDO2）を使うサービスなら上位の YubiKey 5 シリーズと同じように使えます
- 5 シリーズが必要なのは、Yubico OTP・PIV（スマートカード）・OpenPGP・キーへの TOTP 保存を使うときだけです
- 2026 年 10 月下旬、**国内の正規代理店も量販店も在庫が全滅**していました。並行輸入品はファームウェアが分からないので避けました
- **1 本だけは危険です**。全部なくすと、Apple のように二度とログインできなくなるサービスもあります
- YubiKey は「漏れたパスワードでログインされる」ことは防げますが、**企業のサーバーからの流出そのものは防げません**

## はじめに

<!-- hearing:H2 -->
きっかけは、ここ最近の流出ニュースでした。

2026 年 9 月から 10 月にかけて、国内では情報流出の公表が相次ぎました。民間の集計では、9/1〜10/22 の約 50 日間で 335 件、そのうち 10 万件以上の大きな事案が 61 件です。10 月上旬には JPCERT/CC などが一斉に注意喚起を出しました。

出典: 流出事案の件数と注意喚起（S18）

そこに GMO の件が重なりました。FX の自動売買などに使われるサーバーサービスから、証券口座などのログイン情報が流出したという報道です。金銭被害の報告も出ていました。

出典: GMO の件の報道（S19）

パスワードが漏れる前提で考えると、パスワードだけで入れる状態は危ないと感じました。そこで、物理キーの代表である YubiKey を調べ始めました。

## 全体像: YubiKey は何をしてくれるのか

YubiKey は FIDO2（パスキー）の認証器です。サービス側が WebAuthn（ブラウザ標準のパスキーの仕組み）に対応していれば、YubiKey 専用の対応がなくても使えます。

ポイントは以下です。

- ログインするとき、キーに触れないと認証が通りません。パスワードが漏れても、キーがなければ入れません
- パスキーは登録したドメインでしか動きません。偽サイトに誘導されても認証が通らないので、フィッシングに強いです
- キーの中の秘密鍵は取り出せません。そのため、予備のキーはサービスごとに別に登録する必要があります

## Step 0: 要件を決める

自分の条件は以下でした。

- **USB-C と NFC の両方に対応**。PC には USB-C で挿し、iPhone には NFC でかざして使いたい
- **2 本買う**。1 本は持ち歩き、1 本は家に置く（理由は後半で書きます）
- **ファームウェア 5.7 以上**。5.7 より前だとパスキーを 25 個しか保存できず、後からファームウェアを上げることもできません

出典: ファームウェアとパスキー保存数（S04）

## Step 1: モデルを比べる

USB-C と NFC の両方に対応するモデルを比べました。価格は 2026-10-26 時点の表示です。

| 製品 | 日本の価格（税込） | 米国公式 | パスキー保存数 | 対応方式 |
|---|---|---|---|---|
| **Yubico Security Key C NFC** | 5,900 円（Yubion） | $29 | 100 | FIDO2・U2F |
| Yubico YubiKey 5C NFC | 11,700 円（Yubion） | $58 | 100 | FIDO2・U2F・OTP・TOTP・PIV・OpenPGP |
| Google Titan（USB-C） | 未確認 | $35 | 250 | FIDO2・U2F |
| Token2 T2F2 / PIN+ Dual | 未確認 | 約 €26〜$28 | 300 | FIDO2.1・PIV・OpenPGP・OTP |

出典: Yubico 2 モデルの仕様と価格（S01, S02）、国内価格（S13）、Titan と Token2（S05）

Security Key C NFC は「FIDO だけの安いモデル」ですが、古いモデルではありません。ファームウェアは 5.8 で、パスキーの保存数も上位の 5 シリーズと同じ 100 です。

YubiKey 5 NFC と 5C NFC の違いは端子（USB-A か USB-C か）だけで、機能は同じです。

Titan と Token2 は保存数が多く安いですが、今回は YubiKey を使いたかったので候補から外しました。

## Step 2: 使いたいサービスで使えるか

<!-- hearing:H3 -->
一番迷ったのはここでした。安い Security Key で、自分が口座を持っている SBI証券・楽天証券・マネックス証券や、Apple・Google で本当に使えるのか、という点です。

調べた結果は以下です。

| サービス | 方式 | Security Key C NFC | YubiKey 5C NFC |
|---|---|---|---|
| マネックス証券 | パスキー | ○（公式 FAQ に記載） | ○ |
| 三菱UFJ eスマート証券 | パスキー | ○（公式に「外部セキュリティキー」） | ○ |
| SBI証券・楽天証券 | パスキー | ○（公式の記載なし、個人の成功報告あり） | ○ |
| 国内の銀行 | — | 物理キー対応を確認できず | 同左 |
| Apple Account | FIDO | ○ | ○ |
| Google・GitHub・Microsoft など | FIDO / WebAuthn | ○ | ○ |
| Okta の「YubiKey」要素 | Yubico OTP | × | ○ |
| Windows のスマートカードログオン | PIV | × | ○ |
| キーへの TOTP 保存 | OATH | × | ○ |

出典: マネックス証券（S06）、SBI証券・楽天証券（S07）、三菱UFJ eスマート証券（S08）、Apple（S09）、Security Key シリーズの非対応機能と Okta（S03）

結論として、**パスキーで使う分には Security Key C NFC で足ります**。古いから使えない、ということはありませんでした。

ただし、SBI証券と楽天証券は公式には物理キーに触れていません。個人ブログで成功したという報告がある段階なので、実機で試してから頼るつもりです。

## Step 3: どこで買うか

次に困ったのが、どこにも売っていないことでした。

2026-10-26 に国内の店を順に見た結果は以下です。

| 販売店 | 状態 |
|---|---|
| Yubion（ソフト技研、国内の正規代理店） | 全商品が「完売」表示。10/22〜11/1 は注文受付を一時停止 |
| ヨドバシ.com | Security Key C NFC（5,570 円）は販売終了、5C NFC（11,150 円）は販売休止 |
| ビックカメラ | 5C NFC（10,560 円）は販売終了 |
| ソフマップ・アスクル | 在庫切れ |
| モノタロウ・NTT-X Store | 取扱終了・完売 |
| 楽天市場（国内正規品） | 在庫切れ |
| Amazon.co.jp | 在庫はあるが、Amazon Global Store の輸入品 |

出典: 国内の在庫状況（S12）、Amazon の輸入品（S14）

Amazon には在庫がありました。ただ、どれも海外からの輸入品で、中身のファームウェアは商品ページから分かりません。5.7 より前の古い在庫だと、パスキーが 25 個までになってしまいます。

正規代理店の受付停止は「在庫調整と販売体制の準備」のためとされているので、再開を待って正規代理店で買うことにしました。

中古（フリマアプリ）も考えましたが、やめました。物理キーは「信頼できる経路で買った」ことが安全の前提です。前の持ち主の設定が残っていないか、改造されていないかを自分で確かめるのは大変です。

## ハマりどころ

### 似た名前のモデルを取り違えやすい

Amazon で「YubiKey 5C NFC」を検索すると、同じページで 5 NFC（USB-A）や 5C（NFC なし）も選べます。安い方を選ぶと、端子が合わなかったり NFC が無かったりします。

| 表示 | 端子 | NFC | 価格（Amazon、輸入品） |
|---|---|---|---|
| YubiKey 5 NFC | USB-A | あり | 9,793 円 |
| YubiKey 5C | USB-C | **なし** | 10,936 円 |
| YubiKey 5C NFC | USB-C | あり | 13,919 円 |

出典: Amazon の輸入品の価格（S14）

### 値段は上がるのか

需要が急に増えて値上がりするのでは、という心配もありました。調べた範囲では以下です。

- 世界全体では、急に値上がりする気配はありません。Yubico の 2026 年上半期の売上は前年比 -8.8% で、米国の Amazon では 5C NFC が年初に $68 から $58 に下がっていました
- 一方で国内は、2026 年 3 月ごろから売り切れが頻発し、価格も数年前より約 6 割上がったと言われています

出典: Yubico の業績（S15）、米国の価格推移（S16）、国内の値上がり（S17）

国内の品薄はしばらく続きそうです。再開日に早めに注文するのが一番の対策だと考えました。

## 2 本必要な理由

YubiKey は 1 本ではなく 2 本持つのが基本です。

- 1 本なくしても、もう 1 本でログインして、なくしたキーを各サービスから削除できます
- キーの中身は複製もバックアップもできないので、**2 本目も各サービスに登録しておく**必要があります。Yubico も予備は同時に登録するよう勧めています

出典: Yubico の予備キーの推奨（S11）

1 本しかないとどうなるか、も調べました。キーをリセットしても中身が消えるだけで、ログインできるようにはなりません。取り戻す窓口は各サービスです。

| サービス | キーを全部なくしたとき |
|---|---|
| Apple Account | 信頼できるデバイスもなければ、永久に締め出される可能性がある（Apple 公式）。最低 2 本の登録が必須 |
| Google（高度な保護機能） | 復旧申請から本人確認まで数日かかる |
| 一般のサービス | バックアップコードや別の 2 段階認証で復旧。無ければ各社のサポートへ |

出典: Apple（S09）、Google（S10）

## YubiKey で守れないこと

最近の流出ニュースの多くは、企業のサーバーのソフトの穴を突かれたものです。YubiKey が防げるのは「自分のアカウントに他人がログインすること」だけで、それ以外は守備範囲の外です。

| 問題 | YubiKey で防げるか |
|---|---|
| 漏れたパスワードで別のサービスにログインされる | 防げる |
| 偽サイトでのフィッシング | 防げる |
| 企業のサーバーからの流出そのもの | 防げない |
| 流出した氏名・住所・カード番号の悪用 | 防げない |
| 自分の PC のマルウェアによるセッション乗っ取り | 防げない |
| メールや SMS だけでのパスワード再設定 | 防げない（鍵を迂回される） |
| SIM スワップ（携帯番号の乗っ取り） | 防げない |

YubiKey を買ったら終わり、ではありません。パスワードの再設定経路を確かめる、カードの利用通知を ON にする、といった対策と組み合わせる必要があります。

## まとめ

<!-- hearing:H4 -->
まだキーは買えていませんが、失敗ではなく途中だと思っています。何を買うか（Security Key C NFC を 2 本）と、どこで買うか（正規代理店の再開を待つ）は決まりました。

パスキーを使うだけなら、高い 5 シリーズでなくても Security Key C NFC で十分です。買うときは、正規品であることとファームウェアのバージョンを確かめてください。購入できたら、届いたキーのファームウェアと、各サービスでの登録結果をこの記事に追記します。
