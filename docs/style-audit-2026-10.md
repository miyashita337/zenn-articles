# 既存記事スタイル棚卸し（2026-10-04）

対象: Zenn 公開 API（`https://zenn.dev/api/articles?username=<Zenn ユーザー名>`）で取得できた公開記事 **32 本**（2024-12-14〜2026-09-23）。
dashboard 上の非公開下書きは公開 API では取得できないため対象外。

計測方法: 本文 HTML から見出し（h1〜h3）を抽出し、文末を「。」で区切って語尾を分類（コードブロック・表・箇条書きは除外）。文体比率は機械判定の目安。

## 時期で 4 グループに分かれる

| 期 | 期間 | 本数 | テーマ | 文体（文末比率） | 構成の特徴 |
|---|---|---|---|---|---|
| A 雑多 how-to 期 | 2024-12〜2025-10 | 18 | Salesforce / 自作PC / Oracle Cloud / WSL / Obsidian / Serena 等 | です・ます（大半 85〜100%） | 「はじめに」始まり、見出しに絵文字、`1. はじめに` 型の番号見出し、「第N章」型も 3 本 |
| B Claude Code 期 | 2026-02〜04 | 6 | VoiceInk / memory インタビュー / ランチャー / claude-hub / setup script | **だ・である に寄る**（claude-hub 81〜87%、setup script 73%、ランチャー 56%）。memory 記事は です 59% / だ 31% で混在 | TL;DR や「記事メタ情報」など構成がまちまち |
| C OpenClaw 連載 | 2026-05 | 7 | RPi5 構築記 #1〜#7 | です・ます 89〜96% で安定 | **型が揃っている**（下記） |
| D 副業トラック | 2026-09 | 1 | AI 会社の振り返り | です・ます 77% + 体言止め 22% | 見出しが h3 のみ・英語 `Section N:`・読者への問いかけで締める |

## 共通点（揃っているもの）

1. **文体はです・ます が多数派**: 32 本中、だ・である が優勢な 4 本（ランチャー・claude-hub 2 本・setup script）を除く 28 本で です・ます が優勢
2. **実体験ベース**: 「ハマった」「詰まった」「失敗した」を軸にした体験記・作業記録で、評論型の記事はほぼ無い
3. **冒頭は「はじめに」**: 約 20 本が「はじめに」見出しで始まる（C 期は TL;DR → はじめに の順）
4. **末尾に参考リンク**: 約 15 本が「参考リンク / リンク / 参考」節で締める
5. **コードブロック・スクショを多用**: 32 本中 23 本がコードブロック、28 本が画像を含む
6. **連載物は前後の記事へリンク**: 前編・後編、導入編・運用編、#N で「次回予告」「前回」のリンクがある

### C 期（OpenClaw 連載）で確立した型

```
TL;DR（箇条書き 3〜5 行、要点は太字）
はじめに
（なぜ X を選んだか / 全体像 / 案の比較）
Step 0..N または 1..N（手順）
ハマりどころ / ハマりポイントまとめ
まとめ
次回予告
参考リンク
```
補足や後日談は `:::message` で囲む（#3・#5・#6 で 6〜12 個）。

## バラバラなところ

| 観点 | ばらつき | 例 |
|---|---|---|
| 文体 | です・ます / だ・である / 混在 | ランチャー記事は「みんなこう言うだろう」で始まる。memory 記事は同じ記事の中で混在 |
| タイトルの書式 | 先頭に `# ` が入る（5 本）、`【導入編】:` のような隅付き括弧（4 本）、「〜した話」（5 本）、疑問形（3 本）、`#N` 連載形式 | `# 🧠 PySparkで始めるビッグデータ入門` はタイトルに `#` と絵文字が入っている |
| 本文の見出しレベル | 本文で h1 を使う記事が 8 本、h2 を使わず h3 だけの記事が 1 本（AI 会社記事）。claude-hub 導入編は h2 が「記事メタ情報」1 個で、残りは全部 h3 | AI 会社記事は h2 が 0 個 |
| 見出しの番号 | `1.` / `第1章：` / `Step 0:` / `①` / `Section 1:` / `ステップ①` / `4-1.` が混在 | 1 本の中で `1.` と `#3.` が混在する記事もある（Cline） |
| 見出しの絵文字 | A 期の 12 本は使う（自作PC は 10 個）。B〜D 期はほぼ使わない | 🧩 🔍 ✅ 🔗 など |
| 冒頭 | はじめに / TL;DR / 概要 / 対象読者 / きっかけ / 記事メタ情報 / いきなり本文 | 「記事メタ情報」（プラットフォーム等）が公開本文に残っている記事が 1 本ある |
| 締め | 参考リンク / 次回予告 / 「参考になれば幸いです」系（4 本） / 読者への問いかけ / 箇条書きでぷつっと終わる | Salesforce・自作PC は箇条書きのまま終わる |
| 「まとめ」の位置 | 独立した節 / `5. まとめとTIPS` / `第7章：まとめ──` / 無い | 約半数は「まとめ」節が無い |
| 太字の量 | 0〜65 個 | #3〜#7 は 1 本あたり 24〜65 個、Salesforce 2 本・LoRA・AI 会社記事は 0 個 |
| 読者ラベル | 「初心者が挑む！」「自作PC初心者」がタイトルと本文に残っている | 現在の禁止表現に当たる（2025-04 の 2 本） |
| topics | 英小文字が中心で、日本語（`個人開発`）が 1 本 | AI 会社記事 |
